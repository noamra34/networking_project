# 📡 פרויקט גמר – רשתות תקשורת מחשבים (Computer Networks)

ברוכים הבאים לרפוזיטורי של פרויקט הגמר שלנו.
הפרויקט עוסק בניתוח תעבורת רשת ובבניית יישומים בתקשורת נתונים (TCP/IP), ומחולק לשני חלקים עיקריים.

---

## 📚 חלק 1: סימולציית אריזת מידע וניתוח Wireshark

**קבצים:**
`raw_tcp_ip_notebook...ipynb`
`group...csv`
`...pcap`

בחלק זה ביצענו סימולציה של תהליך ה־**Encapsulation (כימוס)** שעובר מידע ברשת.

### מה כולל החלק

* **Jupyter Notebook:**
  מימוש ב־Python של בניית חבילות (Packets) דרך שכבות מודל ה־TCP/IP.

* **Wireshark:**
  לכידת תעבורת רשת וניתוח פרוטוקולים לצורך הבנה כיצד המידע נראה "על הכבל".

> 📄 פירוט מלא על חלק זה מופיע בדוח המסכם המצורף לתיקייה.

## 💬 חלק 2: אפליקציית צ'אט (TCP Chat App) – הגרסה המעודכנת

**קבצים:**
`server_gui.py`
`client_gui.py`
`client.py`

מערכת צ'אט מלאה (דמוית WhatsApp) הפועלת בארכיטקטורת **Client–Server** על גבי פרוטוקול **TCP**.

### ✨ מה חדש בגרסה זו?

* **Server GUI:**
  לוח בקרה גרפי לשרת עם כפתורי הפעלה/עצירה ולוג פעילות בזמן אמת.

* **Client GUI:**
  עיצוב Dark Mode משופר, תצוגת `Hello [Name]`, רשימת מחוברים דינמית ובועות הודעה מעוצבות.

* **Smart Handling:**
  שימוש ב־Multi-Threading למניעת תקיעות וסנכרון מלא בין המשתמשים.

## 🚀 הוראות הפעלה ושימוש (User Guide)

יש לפעול לפי סדר הפעולות הבא **בדיוק**:

---

### 1️⃣ שלב ראשון: הפעלת השרת (Server)

השרת חייב לרוץ לפני שהלקוחות מנסים להתחבר.

1. פתחו טרמינל בתיקיית הפרויקט
2. הריצו:

```bash
python server_gui.py
```

3. ייפתח חלון **Server Control Panel**
4. לחצו על הכפתור הירוק **Start Server**

**בדיקה:**
ודאו שסטטוס השרת השתנה ל־`RUNNING` ושבלוג מופיעה הודעה:

```
Server listening on port 5566
```

🛑 **אזהרה קריטית:**
אין ללחוץ על **Stop Server** או לסגור את חלון השרת בזמן שלקוחות מחוברים.
פעולה זו תגרום ל־**Force Disconnect** וכל אפליקציות הלקוחות ייסגרו מיד.
יש לעצור את השרת רק בסיום הפעילות.

---

### 2️⃣ שלב שני: הפעלת הלקוח (Client)

ניתן להפעיל מספר לקוחות במקביל (בחלונות טרמינל נפרדים).

1. פתחו טרמינל חדש
2. הריצו:

```bash
python client_gui.py
```

לגרסת שורת פקודה (ללא GUI):

```bash
python client.py
```

**התחברות:**

* בחלונית שנפתחה הזינו שם משתמש באנגלית
* לחצו **OK**

🔔 אם השם תפוס, תתקבל הודעת שגיאה ותידרשו לבחור שם אחר.

---

### 3️⃣ שלב שלישי: ביצוע שיחה

לאחר הכניסה לאפליקציה:

* **זיהוי:**
  בצד שמאל למעלה יופיע: `Hello, [Your Name]`

* **אנשי קשר:**
  רשימת המשתמשים המחוברים תופיע בצד שמאל

* **התכתבות:**

  * לחצו על שם משתמש כדי לפתוח צ'אט
  * הקלידו הודעה ולחצו **Enter** או על כפתור ➤

* **הודעות שלא נקראו:**
  יוצגו כמספר ליד שם המשתמש (לדוגמה: `Moshe (3)`)

תהנו! 🎉
